## Изменения для оптимизации под Директ

### Общие улучшения для всех страниц:

1. **H1 должен содержать главный запрос + гео**
2. **Description: 150-160 символов, CTA в конце**
3. **Title: до 60 символов, бренд в конце**
4. **Добавить structured data (LocalBusiness + Service)**
5. **Первый экран: ключевой запрос в первых 100 словах**
6. **Цены/форматы работы явно (от, за, под ключ)**
7. **Блок "Стоимость услуг" с ценовыми якорями**
8. **Гео-привязка в каждом блоке (Москва, МО, Россия)**
9. **Кнопки CTA с микроразметкой потенциального действия**
10. **Номер телефона в шапке для звонков из объявлений**

### Технические SEO-улучшения:

- Скорость загрузки: оптимизация WebP изображений
- Core Web Vitals: LCP < 2.5s, FID < 100ms, CLS < 0.1
- Адаптивность: проверка на всех разрешениях
- Микроразметка Schema.org для всех блоков
- Хлебные крошки (BreadcrumbList)
- FAQ разметка для Яндекса
- Canonical URLs
- Open Graph для соцсетей
- Метрика: цели на форму, кнопки, телефон, Telegram

## Контент-план для повышения качества трафика

### Для каждой страницы добавить:

1. **Блок с ценами/пакетами услуг**
   - Минимальная цена (от)
   - Типовые кейсы с ценой
   - Прозрачность для Директа

2. **Кейсы с результатами**
   - До/после
   - Сроки выполнения
   - Отзыв клиента

3. **Гарантии и сертификаты**
   - Гарантия на работы
   - Опыт (25 лет)
   - Портфолио

4. **Расширенный FAQ (10-15 вопросов)**
   - Частые возражения
   - Коммерческие вопросы
   - Технические детали

5. **Форма с квалификацией лида**
   - Тип задачи (выпадающий список)
   - Срочность
   - Бюджет (диапазоны)

## Landing page checklist для Яндекс Директ

### Обязательные элементы:

- ✅ Соответствие объявлению (заголовок = запрос)
- ✅ Цена/стоимость видна без прокрутки
- ✅ Телефон в шапке (кликабельный tel:)
- ✅ Форма заявки в первом экране
- ✅ Минимум 1500 символов текста
- ✅ Уникальные изображения (не стоки)
- ✅ Отзывы с фото клиентов
- ✅ Гео-привязка (Москва, МО, Россия)
- ✅ Время работы и способы связи
- ✅ ИНН/ОГРН в футере
- ✅ Политика конфиденциальности
- ✅ Скорость загрузки < 3 сек

### Для повышения Quality Score:

- Релевантность: ключ в Title, H1, первом абзаце
- Полезность: ответы на вопросы пользователя
- Юзабилити: простая навигация, читаемость
- Доверие: контакты, отзывы, портфолио
- Конверсия: явный CTA, простая форма

## Метрики для отслеживания

### Цели в Яндекс.Метрике:

1. Отправка формы заявки
2. Клик по телефону
3. Клик по Telegram
4. Клик по кнопке MAX (когда активируется)
5. Просмотр 50%+ страницы (вовлеченность)
6. Время на сайте > 60 сек
7. Просмотр раздела "Примеры работ"
8. Просмотр раздела "Цены/услуги"
9. Переход в другие разделы сайта

### События для электронной коммерции:

- view_item: просмотр страницы услуги
- add_to_cart: начало заполнения формы
- begin_checkout: заполнение всех полей формы
- purchase: успешная отправка формы
