# DESIGN.md — дизайн-система VERTAXO

Стиль: **Industrial Future**. Этот файл — обязательный к прочтению перед версткой любой
страницы или компонента. Все значения ниже — не рекомендации, а жёсткие токены.

## Философия

Строгая инженерная точность и технологичность на тёмном фоне. Минимум декора, максимум
чёткости. Референс-ощущение: приборная панель / инженерный чертёж на тёмном фоне с холодным
акцентом — сама палитра уже отсылает к «синьке» инженерного чертежа (тёмный фон + голубые линии).

Явно ИЗБЕГАТЬ типового «AI slop»: Inter/Arial/Roboto шрифты, фиолетовый градиент на белом фоне,
одинаковые карточки с мягкой тенью по умолчанию, предсказуемый layout без характера.

## Цветовые токены

| Токен (Tailwind var) | Hex | Назначение | Запрещено |
|---|---|---|---|
| `bg` | `#0D1117` | Фон страницы | Использовать под текст/акцент |
| `surface` | `#131A24` | Фон карточек/блоков поверх `bg` | — |
| `text-primary` | `#FFFFFF` | Основной текст, заголовки | — |
| `accent` | `#00C8FF` | ТОЛЬКО главный CTA, ключевые ссылки/акценты | Использовать декоративно/массово |
| `accent-secondary` | `#8B5CF6` | Второстепенный акцент: иконки, hover, разделители | Смешивать с `accent` в одном элементе |
| `metal` | `#D1D5DB` | Второстепенный текст, границы, линии | Использовать как основной текст |

Правило: на одном экране — не больше двух акцентных цветов одновременно. Основной CTA всегда
`accent`; `accent-secondary` — только для вспомогательных элементов.

## Типографика

- Запрещены: Inter, Arial, Roboto, системный шрифт по умолчанию.
- Заголовки: **Unbounded** (Google Fonts, кириллица) — технически-геометричный гротеск.
- Основной текст: **Manrope** (Google Fonts, кириллица) — нейтральный, читаемый на тёмном фоне.
- Акцентный моноширинный: **JetBrains Mono** (Google Fonts, кириллица) — для цифр статистики
  («10+ лет», «500+ проектов»), ощущение «приборной панели/данных».
- Зафиксированная шкала размеров (десктоп / мобильный):

| Уровень | Размер | Вес | Line-height |
|---|---|---|---|
| H1 | 48px / 32px | 700 | 1.15 |
| H2 | 32px / 24px | 600 | 1.2 |
| H3 | 20px / 18px | 600 | 1.3 |
| Body | 16px | 400 | 1.6 |
| Caption | 14px | 400 | 1.5 |

(Использовать только эту шкалу — не изобретать размеры по ходу вёрстки каждой страницы заново.)

## Отступы

Базовая единица — 8px. Шкала: 8 / 16 / 24 / 32 / 48 / 64. Не использовать произвольные
значения вне этой шкалы.

## Компоненты

- Единый радиус скругления для всех карточек/кнопок/полей ввода на сайте: **12px**
  (токен `radius-card`).
- Единая толщина обводки карточек (тонкая, `metal` полупрозрачный).
- Тени: НЕ использовать типовую мягкую box-shadow по умолчанию. Вместо этого — тонкая обводка
  `metal` в состоянии покоя и подсветка `accent`/`accent-secondary` (glow или изменение
  прозрачности обводки) при hover — это же реализует требуемый по спеке эффект «карточка
  оживает при наведении».
- Кнопки: основной CTA — заливка `accent`, текст `bg` (тёмный на светлом акценте) для
  максимального контраста; вторичная кнопка — обводка `metal`/`accent-secondary`, заливка
  прозрачная.
- Иконки — единый набор line-art (тонкая линия, без заливки), цвет `accent-secondary` или
  `metal`. Не смешивать иконки из разных источников/стилей.

## Motion

- Длительности: быстрые взаимодействия 150ms, обычные переходы 300ms.
- Один хорошо поставленный сценарий появления контента при загрузке страницы (staggered
  reveal с `animation-delay`) даёт больше эффекта, чем множество разрозненных мелких анимаций.
- Hover-эффект карточек услуг — лёгкий подъём/увеличение (transform) + смена обводки на
  `accent`, с длительностью 150–300ms, ease-out.

## Анти-паттерны (запрещено)

- Хардкодить hex/px в компонентах вместо токенов из этого файла
- Использовать Inter/Arial/Roboto/системные шрифты
- Использовать фиолетовый градиент на белом фоне или любые клишированные AI-паттерны
- Более двух акцентных цветов на одном экране
- Стоковые декоративные иконки не в едином стиле
- Placeholder-контент на боевых страницах (текст/фото «заглушка»)
