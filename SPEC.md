## 2. Дизайн-требование к каждой посадочной странице (Главная + 3 услуги)

Обязательный состав блоков (Definition of Done для лендинга):

1. Hero — заголовок с сутью услуги + подзаголовок с выгодой + CTA + изображение
2. Список конкретных работ/услуг направления (карточки)
3. «Почему выбирают нас» (цифры/факты, релевантные направлению)
4. Этапы работы (как мы работаем — особенно важно для 3D-печати/инженерии)
5. Примеры работ по направлению (портфолио, отфильтрованное по категории)
6. Отзывы по направлению (отфильтрованные, если данных достаточно)
7. FAQ по направлению
8. Финальный CTA-блок с формой заявки
9. Контакты/футер (общие для сайта)

**Критерий приёмки блока 2 (Definition of Done для каждого из 4 лендингов):**
- [ ] Присутствуют все 9 блоков выше в указанном порядке
- [ ] Форма в блоке 8 реально отправляет заявку (см. `AGENTS.md` verification)
- [ ] У страницы уникальные `<title>`, `<meta description>`, `<h1>` (см. раздел 6)
- [ ] Событие в Яндекс.Метрике фиксируется при отправке формы и клике по CTA
